# Prompts

Las instrucciones de cada función. Pendientes.

Cada prompt tiene dos mitades:

- **La estructura** — umbrales, orden, qué hacer sin datos, reglas duras.
  Sale del Reglamento. Es universal: sirve para cualquier negocio.
- **El criterio** — cómo se juzga un buen gancho para un dueño de negocio,
  cómo se da una corrección sin ofender. Sale del material propio.

Lo que **no** va aquí: la voz, el CTA y las objeciones de un usuario concreto.
Eso es dato del Perfil de Negocio, no lógica del sistema. Un prompt no está
atado a ningún nicho.
